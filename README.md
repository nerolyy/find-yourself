# 🌿 FindYourself

### Найди профессию, которая подходит именно тебе

**FindYourself** — учебный веб-проект, который помогает познакомиться с разными профессиями и выбрать интересное направление для развития.

Идея проекта — собрать информацию о профессиях в одном месте, а в дальнейшем добавить подбор по интересам, профориентационный тест и сохранение избранного.

> 🚧 Проект находится в разработке. Сейчас создаются интерфейс и страницы каталога.

## ✨ Что уже есть

- Главная страница с девятью категориями профессий.
- Боковая панель с разделами помощи в выборе профессии.
- Переход в категорию IT.
- Страница с описаниями шести IT-профессий и местами для изображений.
- Единое оформление: пастельные цвета, шрифт Gentium Plus, карточки и эффекты наведения.
- Футер с автоматически обновляемым годом.

Поиск, фильтры и кнопки боковой панели пока представлены в интерфейсе — их логика ещё не реализована.

## 🚀 Локальный запуск

1. Установите MAMP.
2. Скачайте проект или клонируйте репозиторий через GitHub Desktop.
3. Поместите папку проекта в каталог, указанный в MAMP как **Document Root**.
4. Запустите сервер Apache.
5. Откройте сайт через `http://localhost:8888/ИМЯ_ПАПКИ/`.

Если папка проекта выбрана непосредственно как **Document Root**, откройте `http://localhost:8888/`.

Порт `8888` указан для используемой конфигурации MAMP. Если у вас настроен другой порт Apache, замените его в адресе.

Для текущих страниц подключение базы данных не требуется.
